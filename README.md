# InterpreterDemo (Go)

一个用 Go 实现的**类 C 小型语言解释器**。源代码经「词法分析 → 语法分析（生成 AST）→ 树遍历执行」三段流水线运行，无需任何外部依赖。

本项目是对教学项目 InterpreterDemo 的 Go 语言重写与改进：原版 Java 实现没有 AST，直接在 token 流上边切边执行，控制流依赖移动全局迭代器「跳到 `}`」，无法支持嵌套；Go 版先把整个源文件解析成抽象语法树再遍历执行，控制流天然支持嵌套，同时修复了变量别名共享、比较运算符无求值逻辑、错误被静默吞掉等多个原版缺陷。

## 特性一览

- 5 种基本类型：`int`、`float`、`boolean`、`char`、`string`
- 一维数组：定长、零值初始化、下标越界检查、元素类型检查
- 完整运算符：算术、取模、自增逻辑（短路求值）、位运算、一元运算、比较
- 运算符优先级与 C 一致
- 控制流：`if` / `else` / `else if`、`while`、`break`、`continue`
- 词法级块级作用域，支持变量遮蔽（shadowing）
- `//` 行注释与 `/* ... */` 块注释（未闭合块注释报错）
- 自动跳过 UTF-8 BOM
- 所有词法、语法、运行时错误均携带**行号**，不静默失败

## 快速开始

环境要求：Go 1.22 或更高版本。

```bash
# 克隆后进入项目目录
git clone <repo-url> interpreter-go
cd interpreter-go

# 直接运行内置示例
go run . examples/code.txt
go run . examples/feature_test.txt

# 或编译后运行
go build -o bin/interpreter .
./bin/interpreter examples/code.txt
```

命令行用法：

```text
interpreter [源文件路径]
```

不传参数时默认读取当前目录下的 `code.txt`；文件不存在或程序出错时会向标准错误打印信息并以非零状态码退出。

## 语言参考

### 数据类型

| 类型 | 关键字 | 说明 | 字面量示例 |
|------|--------|------|-----------|
| 整数 | `int` | 64 位有符号整数 | `0`、`42`、`-7` |
| 浮点数 | `float` | 64 位双精度 | `3.14`、`2.0`、`.5` |
| 布尔 | `boolean` | `true` / `false` | `true` |
| 字符 | `char` | 单个字符 | `'A'`、`'\n'` |
| 字符串 | `string` | 不可变字符序列 | `"hello"` |

类型规则：

- 变量有**静态声明类型**，赋值时严格匹配，例如 `int x; x = 1.0;` 会报错（不能把 float 赋给 int）。
- `char` 与 `string` 是不同类型，不能互相赋值；`int` 与 `char` 也不能互赋。
- 算术运算中 `int` 与 `float` 混合时结果提升为 `float`，例如 `1 + 2.0` 得到 `3.0`。
- 整数除法向零截断：`7 / 2 == 3`。
- 浮点输出时整数值显示为 `3.0`（而不是 `3`）。
- 字符串与任意类型做 `+` 运算执行拼接，例如 `"n=" + 1` 得到 `"n=1"`。

### 变量声明

声明以类型关键字开头，可在一条语句中声明多个变量；数组变量在名字后跟 `[长度]`：

```c
int a, b;                 // 两个 int，初始为 0
float pi;                 // 0.0
boolean flag;             // false
char c;                   // 空字符
string name;              // ""
int arr[10];              // 长度 10 的 int 数组，元素全为 0
float m[3], x;            // 可混合声明数组与标量
int n;
n = 5;
int dyn[n];               // 长度可以是任意 int 表达式
```

- 数组长度必须是**非负 int 值**，负数或非整数报错。
- 同一作用域内不允许重复声明同名变量。
- 标量变量自动初始化为类型零值。

### 运算符

优先级**从高到低**（与 C 一致）：

| 优先级 | 运算符 | 含义 | 结合性 |
|--------|--------|------|--------|
| 1 | `[]` | 数组下标 | 左结合 |
| 2 | `-` `!` `~` | 负号 / 逻辑非 / 按位取反 | 右结合 |
| 3 | `*` `/` `%` | 乘、除、取模 | 左结合 |
| 4 | `+` `-` | 加、减 | 左结合 |
| 5 | `<` `<=` `>` `>=` | 关系比较 | 左结合 |
| 6 | `==` `!=` | 相等比较 | 左结合 |
| 7 | `&` | 按位与 | 左结合 |
| 8 | `\|` | 按位或 | 左结合 |
| 9 | `&&` | 逻辑与（短路） | 左结合 |
| 10 | `\|\|` | 逻辑或（短路） | 左结合 |

说明：

- `%` 对浮点数同样可用（按 `math.Mod` 语义）。
- `&`、`|`、`~` 只接受 `int` 操作数。
- 关系与相等运算只接受数值操作数；`==`、`!=` 允许 int 与 float 互比（`1 == 1.0` 为 `true`），布尔与字符/字符串需同类型比较。
- `&&`、`||` 只接受布尔操作数并短路：`false && undef` 不会求值右侧，因此不会报未定义错误。
- 除零（整数与浮点）都会抛出运行时错误。

### 输出：print

`print` 是语句而非函数，可输出零到多个表达式，参数以空格分隔并以换行结尾。以下三种写法等价（也可混用）：

```c
print 1 + 2;          // 3
print 1, 2, 3;        // 1 2 3
print(1 + 2, 3);      // 3 3  —— 函数调用风格
print (1 + 2) * 3;    // 9    —— 括号仅作分组
```

数组整体输出为 `[元素, 元素, ...]` 形式。

### 控制流

```c
if (x > 0) {
    print "positive";
} else if (x == 0) {
    print "zero";
} else {
    print "negative";
}

while (i < 10) {
    if (i == 3) { i = i + 1; continue; }  // 跳过 3
    if (i == 8) { break; }                // 到 8 终止
    i = i + 1;
}
```

- `if` 与 `while` 的条件必须是 `boolean`，条件后的执行体必须是 `{ ... }` 语句块（不允许单语句裸写）。
- `break` / `continue` 只在 `while` 循环内合法；逃逸出所有循环时会报错并指出行号。
- 循环内的块每次执行都会创建新的词法作用域。

### 作用域

- 每个 `{ ... }` 块是一个独立作用域，内层可以读取并遮蔽外层变量。
- 赋值沿作用域链向上查找变量；找不到则报「未声明」错误。
- 注意：在内层声明与外层同名的变量会**遮蔽**外层，对内层变量的修改不影响外层。

### 注释与转义

```c
// 行注释
/* 块注释（不能嵌套，未闭合会报错） */
```

字符串与字符字面量支持的转义序列：`\n`、`\t`、`\r`、`\0`、`\\`、`\"`、`\'`，其他转义按词法错误处理。

## 示例：斐波那契数列

```c
int n, i, a, b, t;
n = 10;
a = 0;
b = 1;
i = 0;
while (i < n) {
    print a;
    t = a + b;
    a = b;
    b = t;
    i = i + 1;
}
```

更多覆盖全部语言特性的示例见 [examples/code.txt](examples/code.txt) 与 [examples/feature_test.txt](examples/feature_test.txt)。

## 错误处理

解释器在三个阶段分别返回携带行号的错误，发生错误时立即终止并输出到标准错误：

```text
line 3: lexical error: unterminated string literal
line 5: syntax error: expected ;, got * ("*")
line 7: runtime error: array index 9 out of bounds (length 5)
```

典型运行时检查包括：变量未声明 / 重复声明、类型不匹配、赋值类型不符、数组下标非整数 / 越界、除零、条件非布尔、不支持多维数组等。

## 项目架构

采用经典编译器前端分层，各包单向依赖：

```text
源代码
  │
  ▼
lexer   词法分析：字符流 → token 序列（记录行号）
  │
  ▼
parser  递归下降语法分析：token 序列 → AST
  │
  ▼
interp  树遍历解释器：遍历 AST，基于词法环境执行
           │
           └─ value：运行时值模型（int/float/bool/char/string/array）
```

目录结构：

```text
interpreter-go/
├── main.go              # 入口：读文件、串联流水线、错误输出
├── token/token.go       # token 类型定义
├── lexer/lexer.go       # 手写词法分析器
│   └── lexer_test.go
├── ast/ast.go           # AST 节点定义
├── parser/parser.go     # 递归下降解析器（含运算符优先级）
├── value/value.go       # 运行时值与类型操作
├── interp/interp.go     # 树遍历解释器
│   └── interp_test.go
└── examples/            # 示例程序
    ├── code.txt
    └── feature_test.txt
```

关键设计：

- **AST 优先**：if/while 只是语法树节点，嵌套与循环体回跳由递归求值天然支持。
- **值模型统一**：`value.Value` 用一个具体结构承载所有类型，数值通过 `AsFloat()` 统一访问，消除字符串往返与异常做控制流。
- **break/continue**：用带类型的 panic 沿调用栈传播，只在最近的 `while` 处被捕获；`Run` 顶层把逃逸信号转为带行号的错误。
- **独立值对象**：`int a, b;` 中每个变量持有独立的值，不存在别名共享。

```bash

go test -cover ./...      # 查看覆盖率
go vet ./...              # 静态检查
gofmt -l .                # 格式检查（无输出即规范）
```

测试覆盖了变量独立性、运算优先级、短路逻辑、数组读写与越界、if-else 链、嵌套循环 break、块级作用域、字符串/字符以及各类错误路径，并包含针对历史缺陷（链式下标 panic、break 行号、print 括号分组、位运算优先级）的回归测试。
